Template JSON

A case template is a JSON document. Applying it to a new case prepends the title prefix, sets the classification, appends the summary and tags, and creates the tasks and note directories.

{
    "name": "tmpl-slug",                <- required, short unique slug
    "display_name": "Template name",
    "description": "Admin-side description",
    "author": "Your name",              <- max 128 chars
    "title_prefix": "[PREFIX]",         <- max 32 chars
    "summary": "Appended to the case description",
    "tags": ["ransomware", "malware"],
    "classification": "malware",        <- name of an existing classification
    "tasks": [
        { "title": "Identify hosts", "description": "...", "tags": ["identify"] }
    ],
    "note_directories": [
        { "title": "Initial summary", "notes": [ { "title": "Note", "content": "..." } ] }
    ]
}
  • name is the only required field.
  • tasks[].title and note_directories[].title are required on each entry.
  • note_groups is the retired pre-2.4 key — the server refuses it and asks for note_directories.
