{# iris-next: time-tracking nudge toggle. OFF by default. #}

Time Tracking

Analyst time is logged per case in 15-minute increments (the clock icon in the case header). Breakdowns by case / person / sector / incident type appear on the dashboard Metrics tab. The optional nudge below reminds analysts about cases they touched recently but logged no time on.

When on, analysts see a dismissible reminder on cases they own or are assigned tasks on (active in the last 7 days) with no time logged. Off by default to avoid adding overhead.
{# /tab-analyst #} {# ── STORAGE ──────────────────────────────────────────────── #}

Data Retention

When a retention period is configured, evidence drives with In use status whose case has been closed for longer than the specified period receive an overdue indicator on the dashboard Inventory tab, prompting a wipe-and-rotate cycle. When the retention period expires the drive is returned to rotation after wiping.

Leave blank to disable. Drives whose case closed more than this many months ago show an Overdue indicator on the Inventory tab.

Capacity Planning

Controls the order-more indicator on the dashboard Inventory tab. The indicator compares the effective 30-day drive supply (available + wipe-eligible within 30 days) against the average case intake rate. An order recommendation with quantity is shown when the runway falls below the target threshold.

Rolling window used to compute average cases per month. Leave blank to use the default (3 months).
Minimum acceptable runway expressed in months of intake. An order recommendation fires when the effective supply falls below this threshold. Leave blank to use the default (2 months).
