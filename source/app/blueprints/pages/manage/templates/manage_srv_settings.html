AI Backend

Backend used by the Tier-1 AI features (case summary, chat assistant, per-event analysis). Defaults seed from AI_BACKEND_* environment variables on first install; values here take precedence afterwards. Add as many backends as you need with + Add backend; each card saves and deletes on its own, the radio picks the active one and is saved with this tab (the active backend cannot be deleted). Each backend names its provider: OpenAI-compatible talks to anything that exposes /v1/chat/completions with the classic request shape (LM Studio, OpenRouter, vLLM, Ollama); OpenAI talks to OpenAI's own API, whose current models want max_completion_tokens and whose reasoning models take no explicit temperature (either shape also adapts itself after one rejected call); AWS Bedrock talks to the Converse API with a Bedrock API key — URL is the runtime endpoint (https://bedrock-runtime.<region>.amazonaws.com), Model is an inference profile ARN / ID or a model ID, pasted as the console shows it. No Bedrock Guardrail is applied. Stored API keys are never shown again; leave the field blank to keep the stored key.

When off, all in-tree AI surfaces fail with "AI backend is not configured" instead of erroring.
